🎙️ Friday — Voice Assistant

A Python-based voice assistant that listens for the wake word **"Friday"** and executes voice commands.

🚀 Features

- 🎤 Voice recognition using SpeechRecognition
- 🔊 Text-to-speech using pyttsx3
- 🌐 Open websites using voice commands
- 🎵 Play songs from the music library
- 🐙 Open GitHub
- ▶️ Open YouTube
- 📸 Open Instagram
- 💼 Open LinkedIn
- 💬 Open Reddit

🛠️ Technologies Used

- Python 3.13
- SpeechRecognition
- PyAudio
- pyttsx3
- Webbrowser
